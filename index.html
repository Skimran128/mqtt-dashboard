System Information

The proposed system is an IoT-enabled Wireless Emergency Alert and Monitoring Network developed using multiple ESP32 devices. Each ESP32 functions as an independent sensing node capable of detecting emergency events such as button press alerts, sensor warnings, or abnormal activity.

Operation WITH Internet

When internet connectivity is available, ESP32 mesh nodes communicate locally while simultaneously sending data to a cloud-based web dashboard. This enables real-time monitoring, node status visualization, and precise identification of emergency locations.

Operation WITHOUT Internet

In the absence of internet connectivity, the system automatically switches to mesh-only mode. ESP32 devices exchange emergency alerts using multi-hop ESP-to-ESP communication. Local alerts are generated through LEDs and buzzers, ensuring uninterrupted operation.
